# GAS受付のセットアップ手順

フォームからの送信を、スプレッドシートに記録できるようにするまでの手順です。
所要時間は15分ほど。晴山さんのGoogleアカウントで作業してください。

---

## 全体の流れ

```
園がフォーム送信
  ↓
GAS（ウェブアプリ）
  ├─ ① スプレッドシートに1行追記   ← 原本。手では編集しない
  ├─ ② Slackに通知                 ← あとから有効化できます
  └─ ③ Notionにページ作成           ← あとから有効化できます
```

①が失敗したら②③には進みません。原本を最優先にしています。

---

## 1. スプレッドシートを作る

新しいスプレッドシートを作り、名前を「HP公開準備フォーム 受付」などにします。

シートの中身は空のままで構いません。見出し行は初回の受付時にGASが自動で作ります。

作ったらURLを控えてください。この部分がスプレッドシートIDです。

```
https://docs.google.com/spreadsheets/d/【ここがID】/edit
```

---

## 2. GASプロジェクトを作る

作ったスプレッドシートを開いた状態で、**拡張機能 → Apps Script** を選びます。

エディタが開いたら、最初から入っている `function myFunction() {}` を全部消して、
このフォルダの `Code.gs` の中身をそのまま貼り付けて保存します。

---

## 3. 設定値を入れる

Apps Scriptの左サイドバーから **⚙ プロジェクトの設定** を開き、
一番下の「スクリプト プロパティ」で以下を追加します。

| プロパティ | 値 | 必須 |
|---|---|---|
| `SHEET_ID` | 手順1で控えたスプレッドシートID | 必須 |
| `SHEET_NAME` | `受付`（変えたい場合のみ） | 任意 |
| `SHARED_TOKEN` | 好きな文字列（例：`promo-domain-2026`） | 任意 |

`SHARED_TOKEN` は、フォーム以外からの投稿を少し減らすためのものです。
静的サイトなのでソースを見れば読めてしまうため、認証の代わりにはなりません。
念のため、他で使っているパスワードは使わないでください。

---

## 4. 動作確認する

エディタ上部の関数選択で `testAppend` を選び、**実行**を押します。

初回は「承認が必要です」と出ます。自分のアカウントを選び、
「詳細」→「（プロジェクト名）に移動」→「許可」と進んでください。
Googleが確認していないアプリという警告が出ますが、自分で作ったものなので問題ありません。

成功すると、スプレッドシートに見出し行とテスト行が1件入ります。
確認できたら、そのテスト行は削除して構いません。

---

## 5. ウェブアプリとして公開する

右上の **デプロイ → 新しいデプロイ**。

- 種類の選択（⚙）→ **ウェブアプリ**
- 次のユーザーとして実行： **自分**
- アクセスできるユーザー： **全員**

「アクセスできるユーザー：全員」でないと、園の先生が送信できません。

デプロイすると **ウェブアプリのURL** が表示されます。
`/exec` で終わるものです。これを控えてください。

```
https://script.google.com/macros/s/AKfycb.../exec
```

`/dev` で終わるURLは開発用で、外部からは使えません。

---

## 6. URLを共有する

控えた `/exec` のURLと、`SHARED_TOKEN` に設定した文字列を教えてください。
`js/app.js` の先頭にある `GAS_ENDPOINT` と `SHARED_TOKEN` に入れて、
GitHubに反映します。

ここまでで、フォーム → スプレッドシートがつながります。

---

## 7.（あとから）Slack通知を足す

Slackの管理画面で Incoming Webhook を作り、発行されたURLを
スクリプトプロパティ `SLACK_WEBHOOK_URL` に入れるだけです。
コードの変更は不要で、次の受付から通知が飛びます。

空のままなら通知しません。

---

## 8.（あとから）Notion連携を足す

1. https://www.notion.so/my-integrations で内部インテグレーションを作り、トークンを取得
2. 受付を溜めるデータベースを作る
3. そのデータベースのページで「…」→ 接続 → 作ったインテグレーションを追加
4. スクリプトプロパティに `NOTION_TOKEN` と `NOTION_DATABASE_ID` を設定

データベース側には、以下のプロパティを用意してください。
名前が違うとNotionへの登録だけが失敗します（スプレッドシートには影響しません）。

| プロパティ名 | 種類 |
|---|---|
| 園名 | タイトル |
| 受付番号 | テキスト |
| ドメイン方式 | セレクト |
| メール | セレクト |
| リスク | セレクト |
| ステータス | セレクト |
| 担当 | テキスト |

ヒアリングの細かい回答はプロパティにせず、ページ本文に流し込みます。

---

## 困ったときは

**送信しても何も起きない**
ブラウザの開発者ツール（F12）のコンソールを見てください。
`GAS_ENDPOINT が空です` と出ていれば、手順6がまだです。

**「送信に失敗しました」と出る**
デプロイ設定の「アクセスできるユーザー」が「全員」になっているか確認してください。
ここが「自分のみ」だと、園の先生からは送信できません。

**コードを直したのに反映されない**
GASは保存しただけでは公開版に反映されません。
**デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン：新バージョン → デプロイ**
で更新してください。URLは変わりません。

**スプレッドシートの列を増やしたい**
`Code.gs` の `COLUMNS` に1行足してください。
なお、列に割り当てのない回答も「未割当の回答」列と「生データ」列に
JSONで残るので、取りこぼしは起きません。
